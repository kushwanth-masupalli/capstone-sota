2. DATASET INGESTION & RIGOROUS PROTOCOL ENFORCEMENT
--------------------------------------------------------------------------------
Dataset:
  * 7,470 full-resolution DICOM PNG images in `data/images/`
  * 7,468 image projection records in `data/indiana_projections.csv`
    (3,818 Frontal, 3,648 Lateral)
  * 3,851 study reports in `data/indiana_reports.csv`

Critical Protocol Decisions & Bug Fixes:
  1. Strict Dual-View Study Filtering:
     - Each study must have at least one Frontal radiograph, at least one Lateral
       radiograph, and non-empty `findings`.
     - Discarded 174 single-view studies to strictly conform with published R2Gen
       dual-view split protocols (~2,069 train / 296 val / 590 test).
     - Locked split counts in `processed/splits.json`:
       * Train: 2,060 studies
       * Val:     294 studies
       * Test:    589 studies
       * Total: 2,943 paired studies

  2. Word-Preserving Text Cleaner:
     - Fixed common catastrophic regex bug `re.sub(r'x+', '', text)` which corrupted
       real clinical words ("pneumothorax" -> "pneumothora", "exam" -> "eam").
     - Replaced with word-boundary anonymization replacement:
       `re.sub(r'\bx{2,}\b', ' ', text)` and `re.sub(r'\bx-\s*', '', text)`.
     - Target findings truncated to MAX_WORDS = 60 to prevent mid-sentence cutoff.

  3. Retrieval Leakage Elimination:
     - The FAISS retrieval index is built strictly over train studies only.
     - Val and test studies are NEVER indexed.
     - During training, the query study's own UID is explicitly excluded from the
       retrieval result pool (guards against model learning trivial copy-paste).

  4. Official Metric Computation:
     - All headline metrics are computed via `pycocoevalcap` backed by Java 1.8 and
       the official Stanford PTBTokenizer (BLEU-1..4, METEOR 1.5, ROUGE-L, CIDEr).

4. VISION ENCODER & CLINICAL REPRESENTATION PROBE
--------------------------------------------------------------------------------
Encoder: `microsoft/rad-dino` (ViT-B/14, 518x518 native resolution, D_enc = 768).
  * Native patch grid: 37x37 = 1,369 spatial patch tokens + 1 CLS token.
  * Spatial Token Pooling: `nn.AdaptiveAvgPool2d((12, 12))` maps the 37x37 grid
    to exactly 144 visual tokens per view (288 dual-view tokens total).
  * Global study embedding: concat(mean(frontal), mean(lateral)) = 1,536-dim vector,
    L2-normalized for cosine similarity.
  * All 2,943 studies pre-computed and cached to `processed/feats/{uid}.pt` in fp16.
  * Built `processed/train_faiss.index` (IndexFlatIP, 1,536-dim, N=2,060).

14-Finding Linear Probe Performance:
  * Achieved Macro-AUC: 0.8135 across all 14 CheXpert/NIH categories on cached features!
  * Per-Finding Breakdown:
    - Pleural Effusion          : AUC = 0.9670
    - Pneumonia                 : AUC = 0.9408
    - Cardiomegaly              : AUC = 0.8936
    - Pneumothorax              : AUC = 0.8688
    - Consolidation             : AUC = 0.8628
    - No Finding                : AUC = 0.8462
    - Support Devices           : AUC = 0.8277
    - Edema                     : AUC = 0.8254
    - Lung Opacity              : AUC = 0.8241
    - Atelectasis               : AUC = 0.7975
    - Pleural Other             : AUC = 0.7790
    - Fracture                  : AUC = 0.7634
    - Lung Lesion               : AUC = 0.6931
    - Enlarged Cardiomediastinum: AUC = 0.5000
  * Generated 5-fold Out-Of-Fold (OOF) training priors (`processed/train_oof_priors.json`),
    ensuring training prompt indicators mirror noisy test-time predictions.

5. REPOSITORY ARCHITECTURE & SOURCE MODULES
--------------------------------------------------------------------------------
src/
├── prepare_data.py
│   - Ingests raw CSVs and images.
│   - Performs word-preserving text cleaning and 60-word capping.
│   - Splits into locked train (2,060), val (294), and test (589) studies.
│   - Generates 14-finding ground truth multi-labels (`processed/train_labels.json`).
│
├── evaluate.py
│   - Computes headline metrics via Java PTBTokenizer + pycocoevalcap.
│   - Exposes fast Python LCS ROUGE-L proxy and `mbr_select()` for MBR decoding.
│   - Evaluates E0 (normal baseline) and E1 (retrieval baseline).
│
├── cache_features.py
│   - Runs frozen `microsoft/rad-dino` forward pass on all 2,943 studies.
│   - Reshapes ViT patches and applies AdaptiveAvgPool2d((12, 12)) -> 144 tokens/view.
│   - Builds `processed/train_faiss.index` and metadata.
│   - Evaluates E1 retrieval hurdle.
│   - Trains 14-finding probe and produces 5-fold OOF training priors.
│
├── dataset.py
│   - `IUReportDataset`: Loads cached visual features, queries FAISS dynamically
│     with train-time UID exclusion, formats OOF clinical indicators, and formats
│     ChatML prompt with 288 `<|image_pad|>` tokens.
│   - `collate_fn`: Dynamic sequence padding with assistant-only loss masking (-100).
│
├── model.py
│   - `DualViewRAGVLM`:
│       * Learned frontal and lateral view embeddings: `[1, 144, 768]`.
│       * 2-layer MLP Projector: `Linear(768 -> 2048) -> GELU -> Linear(2048 -> 2048)`.
│       * Auxiliary Classifier Head: `Linear(1536 -> 14)` on global dual-view vector.
│       * Base LLM: `Qwen/Qwen2.5-3B-Instruct` with 4-bit NF4 QLoRA (r=32, alpha=64).
│       * Total Loss: `L = L_CE(report tokens) + 0.2 * L_BCE(14 findings)`.
│       * Autoregressive beam search & stochastic sampling generation.
│
├── train_sft.py
│   - Two-stage training pipeline:
│       * Stage 1: Warmup Projector + Head (3 epochs, lr=1e-3, LLM frozen).
│       * Stage 2: Full SFT (10 epochs, LoRA lr=1e-4, Projector lr=2e-5, Head lr=1e-4).
│   - Early stopping on validation ROUGE-L (patience 3).
│   - Gradient accumulation (effective batch size 16), AdamW, cosine schedule.
│   - Memory tracking and timing per epoch.
│
├── generate_mbr.py
│   - Candidate pool generation (N=16: top-4 beams + 12 diverse stochastic samples at T=0.7).
│   - Fast Python MBR consensus selection (`0.6*ROUGE-L + 0.4*ngram_F1`).
│   - Executes official `pycocoevalcap` scoring on consensus outputs.
│
└── create_colab_notebook.py
    - Programmatically compiles `notebooks/colab_runner.ipynb`.

notebooks/
└── colab_runner.ipynb
    - 1-click execution notebook configured for Google Colab GPU (T4 / L4 / A100).
